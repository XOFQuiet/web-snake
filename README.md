# HTML Snake Game

A classic retro Snake game built with vanilla HTML, CSS, and JavaScript. Playable directly in any modern web browser with no installation or external dependencies required.

**Features**

* **Responsive Control:** Smooth directional inputs using arrow keys or WASD.
* **Score Tracking:** Live score counter that updates as you eat food, tracking your current session.
* **Retro Aesthetics:** Minimalist design inspired by classic arcade interfaces.
* **Zero Dependencies:** Pure frontend implementation utilizing HTML5 Canvas and vanilla JavaScript.

**Project Structure**

```text
snake-game/
├── index.html    # Main HTML structure and Canvas element
├── style.css     # Styling and layout centering
└── script.js     # Game loop, collision detection, and rendering logic

```

**Getting Started**

1. Clone the repository:
```bash
git clone https://github.com/xofquiet/web-snake.git

```


2. Navigate to the project directory:
```bash
cd web-snake

```


3. Open `index.html` in your web browser of choice to start playing.

**How to Play**

* Use the **Arrow Keys** (Up, Down, Left, Right) to navigate the snake.
* Consume the red food pellets to grow longer and increase your score.
* Avoid colliding with the game boundaries or the snake's own tail.
